# MATISA — INTERACTION CONTRACT & SYSTEM INVENTORY

This document defines the canonical interaction contract for every visible interactive element across every routed screen in Matisa. Every element has a defined user action, authentication requirement, handler, canonical service, server command/query, database table, success result, failure result, navigation destination, cache invalidation, realtime effect, and notification effect.

---
